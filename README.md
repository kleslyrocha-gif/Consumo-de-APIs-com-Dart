# Consumo-de-APIs-com-Dart
#  Open Library

Projeto em Dart para consultar livros utilizando a API pública Open Library.

##  Como executar

Entre na pasta do projeto:

```bash
cd atividade_open_library
```

Instale as dependências:

```bash
dart pub get
```

Execute:

```bash
dart run
```

## Funcionalidades

* Consultar livros por nome ou autor;
* Exibir informações dos livros;
* Armazenar histórico de consultas;
* Limpar histórico.

##  API

Open Library:

```text
https://openlibrary.org/search.json
```
