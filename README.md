# Consumo-de-APIs-com-Dart
Consulta de Livros - Open Library

Projeto desenvolvido em Dart para realizar consultas de livros utilizando a API pública Open Library.

Aluno: Klesly de Souza Rocha

Sobre o projeto:
A aplicação permite que o usuário pesquise livros pelo nome ou pelo autor.
Os dados são obtidos através da API Open Library e apresentados diretamente no terminal.
O projeto foi desenvolvido utilizando Dart puro, sem Flutter.

 API utilizada:
Open Library
Endpoint utilizado:
https://openlibrary.org/search.json

#Como executar

Entre na pasta do projeto:
cd atividade_open_library

Instale as dependências:
dart pub get

Execute:
dart run

Funcionalidades
Consultar livros por nome ou autor;
Exibir informações dos livros;
Armazenar histórico de consultas;
Limpar histórico.
